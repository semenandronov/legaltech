# Chat Architecture v6.0

## Обзор

Чат-система использует **ReAct паттерн** (Reason + Act) для интеллектуальной обработки запросов пользователей. Агент сам выбирает какие инструменты использовать для ответа на вопрос.

### Ключевые особенности v6.0:
- **Reflection Pattern** — самопроверка ответов для снижения ошибок на 30%
- **Citation Verification** — автоматическая проверка цитат через ГАРАНТ
- **Confidence Scores** — оценка уверенности в каждом ответе

## Режимы работы

### 1. Базовый режим (ничего не включено)
- **Агент:** ReActChatAgent
- **Инструменты:** 11 базовых
- **LLM:** GigaChat (стандартный)

### 2. Режим ГАРАНТ (legal_research=True)
- **Агент:** ReActChatAgent
- **Инструменты:** 11 базовых + 2 ГАРАНТ
- **LLM:** GigaChat (стандартный)
- **Дополнительно:** Поиск в правовой базе ГАРАНТ

### 3. Режим Deep Think (deep_think=True)
- **Агент:** ReActChatAgent
- **Инструменты:** 11 базовых
- **LLM:** GigaChat Pro (более мощный)
- **Дополнительно:** 7 фаз анализа через ThinkingService

### 4. Режим Draft (draft_mode=True)
- **Обработчик:** DraftHandler
- **Инструменты:** Template Graph
- **LLM:** GigaChat (стандартный)
- **Результат:** Создание документа в редакторе

## ReAct цикл

```
User Question
     ↓
[THINK] → LLM анализирует вопрос
     ↓
[SELECT TOOL] → LLM выбирает инструмент
     ↓
[EXECUTE] → Вызов инструмента
     ↓
[OBSERVE] → Получение результата
     ↓
[REPEAT or ANSWER] → Ещё инструменты или финальный ответ
```

## ThinkingService (Deep Think)

При включённом `deep_think=True` перед основным ответом выполняется глубокий анализ:

### Фазы анализа:
1. **UNDERSTANDING** — Понимание вопроса
2. **CONTEXT_ANALYSIS** — Анализ контекста
3. **REASONING** — Логические рассуждения
4. **COUNTERARGUMENTS** — Контраргументы
5. **LEGAL_ANALYSIS** — Правовой анализ
6. **PRECEDENTS** — Анализ прецедентов
7. **SYNTHESIS** — Синтез ответа

## SSE События

Чат использует Server-Sent Events для стриминга:

| Событие | Описание |
|---------|----------|
| `textDelta` | Текст ответа (инкрементально) |
| `reasoning` | Шаги мышления (фаза, номер, контент) |
| `agent_step` | Действие агента (tool call) |
| `citations` | Цитаты из источников |
| `document_created` | Создан документ (draft mode) |
| `confidence_score` | **NEW v6.0:** Оценка уверенности в ответе |
| `citation_verification` | **NEW v6.0:** Результаты проверки цитат |
| `reflection_result` | **NEW v6.0:** Результаты самопроверки |
| `error` | Ошибка |

## Reflection Pattern (NEW v6.0)

Самопроверка ответов агента для повышения качества:

```
Agent Answer
     ↓
[REFLECTION] → LLM проверяет ответ на:
  • Релевантность (отвечает ли на вопрос?)
  • Полноту (все аспекты рассмотрены?)
  • Точность (факты верны?)
  • Источники (указаны ли?)
  • Логику (выводы последовательны?)
  • Галлюцинации (нет ли выдуманного?)
     ↓
[SCORE] → Confidence Score (0.0 - 1.0)
     ↓
[IMPROVE] → Если проблемы — улучшенный ответ
```

### Уровни уверенности:
- **high** (≥0.9) — Ответ надёжный, источники проверены
- **medium** (0.7-0.9) — Ответ корректный, возможны уточнения
- **low** (0.5-0.7) — Есть сомнения, рекомендуется проверка
- **very_low** (<0.5) — Ответ требует ручной проверки

## Citation Verification (NEW v6.0)

Автоматическая проверка цитат через ГАРАНТ:

```
Answer with citations (ст. 395 ГК РФ, п. 1 ст. 10 ГК РФ)
     ↓
[EXTRACT] → Находим все цитаты в тексте
     ↓
[VERIFY] → Проверяем каждую через ГАРАНТ API
     ↓
[RESULT] → Статусы: verified ✓, not_found ✗, partial ~
```

### Типы цитат:
- Статьи кодексов: `ст. 395 ГК РФ`
- Пункты статей: `п. 1 ст. 395 ГК РФ`
- Федеральные законы: `ФЗ "О защите прав потребителей"`
- Постановления Пленума: `Постановление Пленума ВС РФ`
- Судебные решения: `дело № А40-12345/2023`

## Примеры использования

### Обзорный вопрос
```
User: "О чём это дело?"
Agent: analyze_all_documents("О чём это дело?", "summarize")
→ Map-Reduce суммаризация всех документов
```

### Конкретный вопрос
```
User: "Какая сумма в договоре?"
Agent: search_in_documents("сумма договор цена", k=15)
→ Поиск по документам + ответ
```

### Правовой вопрос (ГАРАНТ включён)
```
User: "Статья 395 ГК РФ"
Agent: search_garant("статья 395 ГК РФ", "law", 5)
→ Поиск в ГАРАНТ + полный текст статьи
```

### Создание документа (Draft mode)
```
User: "Составь претензию о возврате денег"
DraftHandler: Template Graph → Создание документа
→ Документ открывается в редакторе
```
